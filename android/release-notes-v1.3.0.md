# itouOJ Android App 1.3

## 更新內容

- 手機實作題可左右滑動切換題目與程式編輯區；App 在原本的底部導覽列上方新增「題目／程式」切換列。
- 實作題改用 `a001` 這類一碼小寫英文加三碼數字的代碼，搜尋也能直接輸入代碼。
- 編輯器支援程式碼自動補全；題目列表與題目頁排版改善。

App 會連線載入正式網站，網站功能更新後，既有 App 也會同步取得新的頁面介面。

## 安裝

下載 `itouOJ-1.3.apk` 安裝；已安裝舊版的使用者可直接更新，不必先解除安裝。
