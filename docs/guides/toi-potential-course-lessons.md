# TOI 潛力組逐題教學

本學習路徑涵蓋 2026-10-20 本站公開題庫中全部 135 題潛力組題目：a108～a155、a269～a355，共 194 組公開範例。每題提供個別解題推導、複雜度、常見陷阱、具體數值的步驟動畫，以及可獨立執行的 C++17／Python 3 程式；不是將同一份主題範本當成各題解答。

其中 134 題為一般參考解法；a344 的來源本身已標記待審，公式與第一組範例不可能同時成立。該題僅保留帶有明顯警告的公式分析與示範程式，不能稱為已通過範例或可提交解答，也沒有更改原題、測資或官方範例。

## 使用與資料範圍

- `/courses/toi-potential`：依 10 個主題、教學難度、題號、名稱或方法選課。單元內由簡到難排列，未篩選時先收合單元，避免一次顯示全部教材。
- `/courses/toi-potential/lessons/<題號>`：逐題教學、步驟播放、雙語程式與前後課導覽。
- `/courses`：有相符的實際題目時顯示課程卡片；登入後只計算本人的不重複 AC 題數。
- `/problems/<題號>`：有教材且仍有 `TOI 歷屆` 標籤時，顯示對應「教學」入口。

這是程式內建的公開學習路徑，不新增 `Course`、`CourseMember`，不需加入代碼或額外 seed。既有「TOI 新手組 練習」、APCS、CPE 與一般課程不變。潛力組與新手組共用 `TOI 歷屆` 標籤，因此必須同時比對教材題號清單，不可只憑標籤計算題目或進度。

所有入口同時檢查實際資料庫中的實作題類型、題號、目前標籤與公開狀態。普通使用者不能因教材已打包而讀取已隱藏、移除標籤、刪除或改成非實作題的教材。管理員可預覽未公開實作題。前後課只列出目前有權閱讀的題目。既有資料庫課程的教學入口優先，潛力組入口作為相符題目的後備連結。

`src/lib/toiPotentialProblemCatalog.ts` 保存公開題名與範例，不含隱藏測資。題敘以本站當日公開內容為準；原 TOI／ZeroJudge 版本若有差異，需明確說明，不能默默替換規則或修改範例以遷就解法。新加入題庫的題號不會自動取得不存在的教材。

只有目前這一課的程式與動畫資料傳給互動元件；不將整份 135 題教材送入瀏覽器。清單連結關閉預抓取，避免展開單元時同時預抓全部課程。

## 驗證

完整覆蓋、欄位與動畫索引檢查：

```sh
npm run test:toi-potential-lessons
```

編譯／執行全部 C++17、Python 公開範例：

```sh
npm run test:toi-potential-lessons -- --python python3 --cxx g++
```

這是嚴格模式，會如實在 a344 的第一個範例失敗。CI 顯式使用以下診斷模式：134 題的 191 組範例仍逐一嚴格比對；a344 另編譯／執行兩個語言，斷言其餘兩組範例吻合、唯一衝突仍為「輸入 1：公式 2、原範例 1」。這個已知衝突不算範例通過，若原範例或程式改成掩蓋問題，診斷也必須失敗。

```sh
npm run test:toi-potential-lessons -- --python python3 --cxx g++ --check-known-source-conflicts
```

可用 `--batch 1` 至 `--batch 6`（每批 22 題）、`--file batch1/part1`（11 題）、`--file final`（3 題）分批驗證，或用 `--code a108,a109` 限制題號。輸出比對保留內部空白與空白行，只正規化換行及行尾空白。Windows 的 `--temp-root`、`--no-pch`、`--compile-only-cxx` 與 CPE 共用跨平台程序執行器；編譯成功不能代替執行通過，若端點保護阻擋新程式，保留安全設定並交由 Linux CI 執行。

獨立演算法對照（直接執行教材中的 Python 程式，不使用另一份解法副本）：

```sh
npm run test:toi-potential-algorithms -- --python python3
```

此套持續性回歸涵蓋 a353 的逐空地 BFS 暴力對照、a354 的所有小型二元樹形狀枚舉、a355 的小型有向圖逐起點 BFS 對照，以及百萬格、千節點與兩萬筆查詢等限制級輸入。各批另有逐題範例、獨立小例與邊界驗證。這些測試不等於正式評測的隱藏測資 AC。

HTTP 整合驗證：

```sh
npm run test:toi-potential-course
```

整合測試建立拋棄式資料庫並套用 migrations，不使用正式資料庫；涵蓋搜尋、主題／難度、重複 query 參數、權限、前後課、題目頁入口、進度去重，以及既有新手組課程與會員不受影響。若已完成 production build，可設 `TOI_POTENTIAL_TEST_PRODUCTION=1` 重用結果；暫存位置可設 `TOI_POTENTIAL_TEST_TEMP_ROOT`。CI 執行 production HTTP 測試及全部雙語公開範例。

## 題敘假設與限制

- a344：原題公式、範例與主／分組上限有明確矛盾，已列為規格待釐清；`toiPotentialSourceIssues.ts` 保存原始衝突，不以對 n=1 特判冒充正確解答。
- a147 的精確勝負搜尋最壞仍為指數級；各批最大規模測試在共用 Windows 主機負載下時間波動很大，不代表已符合正式評測時間限制或通過隱藏測資。
- a322 的六面鄰格、a323 的正除數與 32 位元有號位元表示、a324 未定義的計數上界、a325 的重複座標、a326 的空牌堆／全平手機率，以及 a345 的起終點陷阱重疊等未完備規則，均在對應教學明列採用的慣例，不宣稱來源已保證該慣例。
- a355 本地題敘未明訂查詢 A=B 時是否必須搭乘至少一次航班；教材採通常的可達性定義，允許零段路徑，自我可達為真。範例未區分此情形，不能宣稱隱藏評測已確認該慣例。
- a354 不假設任意後綴的最小程度單調；先移除被支配候選才二分，並以獨立樹形枚舉驗證。最大總和可到 10¹²，C++ 不能使用 32 位元總和。
- 公開範例與 HTTP 測試不能取代瀏覽器的實際視覺／互動檢查；若視覺驗證未完成，需在 PR 中另外列明。
