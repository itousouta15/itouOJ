# 教材正確性稽核與修正

本輪以 2026-10-20 重新取得的公開題敘為準。公開程式題共 847 題，既有教材目錄涵蓋 771 題：APCS 入門 9、APCS 歷屆 104、TOI 新手 135、TOI 潛力 135、CPE 388。另 76 題不在既有教材目錄；本次沒有將它們冒充已完成教材，也沒有恢復使用者先前要求移除的 a001–a005。

## 根因與修正

- TOI 新手組原本把 135 個題號導向九份主題示範程式，並非各題解答。移除此 fallback，改成 135 份對應實際題意的教材，各含 C++17、Python、公開範例、推導、陷阱、複雜度與逐步動畫。a086 現在正確計算芝麻、花生需求、十顆一盒的向上取整與剩餘數。
- 主題分類依各題實際解法重建；原有課程排序、可見性與上一課／下一課規則保留。教學 URL 不接受同題號的非程式題；不存在題號與物件原型屬性不能被判為已有教材。
- APCS 修正範例與動畫對齊、a455 的錯誤陷阱說明，以及數個忽略輸入儲存／惰性堆積成本的複雜度敘述。詳見 [APCS 紀錄](apcs-tutorial-audit.md)。
- CPE 修正 a559 動畫遞迴數列、a824 Python 先轉小寫導致 Unicode 字元被誤當英文的分詞問題。詳見 [CPE 紀錄](cpe-tutorial-audit.md)。

## 驗證層級

`npm run test:tutorial-coverage` 檢查 771 個精確題號、教材欄位、動畫索引、resolver 及公開範例對應。可加 `-- --source-snapshot PATH` 對照當日完整來源。這是資料契約檢查，不是演算法正確性證明。

參考程式直接由 TypeScript 教材匯出，不用另一份程式副本代替。除公開範例外，各批新增固定種子的暴力枚舉、獨立模型與邊界回歸；每批的實際案例數、未覆蓋範圍與執行方式分別記於：

- [新手第一批](toi-beginner-batch1-audit.md)、[第二批](toi-beginner-batch2-audit.md)、[第三批](toi-beginner-batch3-audit.md)
- [潛力組紀錄](toi-potential-tutorial-audit.md)
- 上述 APCS、CPE 紀錄

本機已通過 135 題新手組 Python 公開範例、771 題來源範例對應、TypeScript 與 ESLint。Windows 應用程式控制限制新 C++ 二進位執行，未停用或繞過；本機編譯成功不算執行成功。Linux CI 新增六組分批回歸，實際執行 C++ 與 Python；CPE 只跑針對性 oracle，不恢復已移除的全題庫編譯矩陣。頁面整合測試使用拋棄式資料庫，遍歷全部 135 個新手教學 URL、範例、C++ 顯示及儲存排序。

本機 production build 在 KaTeX CSS 的 Turbopack 子程序啟動時失敗；最終 build／HTTP 測試以 PR 的 Linux CI 結果為準。沒有讀寫正式資料庫、提交正式評測、合併 PR 或部署。

## 不能宣告已解決的規格問題

- a159：極值並列時未指定搬運來源／目的盒。教材明列首次出現只是程式約定，沒有為歧義輸入捏造評測答案。
- a229：本站與官方 [Supermarket 原題](https://tpmso.k12ea.gov.tw/toi/wp-content/uploads/question/202310/Supermarket.pdf) 都未指定最快櫃檯平手規則，也未保證唯一。教材明列較小編號只是實作約定，仍需出題者確認。
- a344：公式推出 T₁=2，但公開範例期望 1。保留原範例與既有警告，不改成假通過；分析程式不是已驗證可提交解答。

其餘題意不完整、數值範圍與最大測資效能缺口見各批報告。人工檢視與有限測試不等於全部隱藏測資 AC；本輪不作「771 題全部正確」的宣告。
