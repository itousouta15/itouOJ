本文件記錄第一輪實際證據。後續針對當時尚未完整閱讀的 C++／推導／複雜度等欄位另做第二輪，見 [a460–a619](cpe-additional-review-early.md)、[a620–a759](cpe-additional-review.md)、[a760–a803](cpe-additional-review-late1.md)、[a804–a847](cpe-additional-review-late2.md)。各報告保留發現時的版本、反例、修正狀態與剩餘界限，不以第一輪公開範例通過替代後續語意閱讀。

整合修正另包括 a522 的熱量溢位、a595 的不可達標記／距離加法、a685 的負零格式化、a747 的查詢空鍵插入、a794 的整錢包 DP 大量配置，以及 a828／a831／a836 的固定寬度整數讀取。後三題只需輸出、比較或集合相等，改用正規十進位字串；不藉由放寬 Python 安全設定處理長數字。其他已確認的容器與輸入儲存成本註記也已修正。

追加修正 a779 的大座標浮點消去（右端點排序與覆蓋改用精確根式比較）、a796 的短小數金額位置解析，以及 a790／a797 的 CRLF 行尾處理。整合後本機重跑 **31 題、11,985 組配對用 oracle／邊界案例**的 Python 程式，另有一組超出 C++ 輸入契約的 Python 任意精度哨兵反例，均通過；25 題變更教材的公開範例也全部通過。這些是本機 Python 執行數，不冒充本機 C++ 執行數；最新 C++ 與完整應用程式驗證以 PR Linux CI 為準。

共用回歸仍為 `check-cpe-tutorial-audit.mjs/.py`，新增精確 Fraction、水量／期限大數、負零、異序詞、實體硬幣子集合、整數排序與集合反例。C++ 的 a522／a595 明列有號 64 位元單一輸入及 GNU __int128 擴充契約；沒有把未列上限的原題說成已保證任意整數輸入。所有原始公開範例與期望值維持不變。

## 題敘來源

採用 `../tutorial-audit-source/all-problems.json` 的 CPE 子集合（當天取得的 771 題完整快照）。它的 388 筆 CPE 題名、題敘與所有公開範例，與先前 `../cpe-course-source/problems.json` 逐筆相同。本次亦重新讀取 388 個 `https://oj.itousouta.me/problems/<code>` 公開頁，比對來源新鮮度；公開範例另與 `cpeProblemCatalog.ts` 比對，沒有直接更動 catalog。

快照是渲染 HTML 的文字擷取，不是原始數學規格。KaTeX 重複的 MathML／可視文字、失去上標的文字不能串接解讀為新數值。規格不清楚時保留不確定性，不由 UVa 題號或範例反推未聲明的規則。本次兩項修正均不依賴數學排版擷取。

## 已確認並修正

| 題號 | 修正與可重現證據 |
| --- | --- |
| a559 | 動畫宣告 N=6、M=5，卻顯示 `1,2,3,2,4,5`。依三項和遞迴，第五項為 `(2+3+2)%5+1=3`，第六項為 4；已改標題與末幀為 `1,2,3,2,3,4`。答案仍為 3，參考算法不需更動。新增由種子重新產生序列的動畫檢查，以及 324 個暴力子陣列案例。 |
| a824 | Python 原本對全文 `.lower()` 後才擷取 `[a-z]+`。例如 `Kelvin İce` 會額外產生 `kelvin`、`i`，但題意的英文片段為 `elvin`、`ce`，也與 C++ 的 ASCII 分詞不同。改為先擷取 `[A-Za-z]+`，再對片段轉小寫，並修正文解。新增 UTF-8、標點、數字、跨行、重複詞與無結尾換行的分詞反例。ASCII 公開範例結果不變。 |

兩個回歸檢查均先在原教材上重現失敗，修正後通過。Windows 子 Python 明確以 `-X utf8` 執行，避免把主機預設編碼的差異誤報為教材錯誤。

## 重跑方式

從儲存庫根目錄執行；腳本不更新 catalog、不送出評測、不寫資料庫，也不重新啟用 bulk CPE CI matrix。

```sh
# 新增獨立 oracle 與已修正動畫；不需網路或外部快照
node --import ./scripts/ctf-test-loader.mjs scripts/lib/check-cpe-tutorial-audit.mjs --traces --python python3

# 修正題號的針對性回歸
node --import ./scripts/ctf-test-loader.mjs scripts/lib/check-cpe-tutorial-audit.mjs --codes a559,a824 --traces --python python3

# 可執行原生程式的環境：編譯並執行同一批獨立 oracle
node --import ./scripts/ctf-test-loader.mjs scripts/lib/check-cpe-tutorial-audit.mjs --traces --python python3 --cxx g++

# 原生程式遭主機攔截時，只編譯 C++；輸出會明示 compiled 而非 executed
node --import ./scripts/ctf-test-loader.mjs scripts/lib/check-cpe-tutorial-audit.mjs --python python3 --cxx clang++ --compile-only-cxx

# 選用：公開頁與新快照的新鮮度比對，需要網路與該外部快照
node --import ./scripts/ctf-test-loader.mjs scripts/lib/check-cpe-tutorial-audit.mjs --live --snapshot ../tutorial-audit-source/all-problems.json
```

現有 `scripts/verify-cpe-lessons.mjs` 另負責 388 題結構及公開範例；父工作負責針對性 CI 與整合。新 regression 只在 `scripts/lib/check-cpe-tutorial-audit.*`，沒有修改既有 harness。
