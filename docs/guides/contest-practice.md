# 競賽練習題（本站自編）

依常見的程式競賽考點自編，不是歷屆原題，也不保證出現在未來考試。

| 題目 | 練習重點 |
| --- | --- |
| 矩形雨量查詢 | 二維前綴和、含負數與大整數的區間查詢 |
| 貨車最低載重 | 二分搜尋答案、連續分段的可行性判斷 |
| 課程先修順序 | 拓樸排序、字典序最小、循環與重複邊 |
| 山路最短行車時間 | 帶權單向圖最短路、不可達與平行邊 |
| 嚴格上升的訓練日 | 最長嚴格遞增子序列與重複值 |
| 裝備選擇 | 0/1 背包，每件只能使用一次 |

每題兩組公開範例及多組自製隱藏測資，全部按題面限制產生。建議依表格順序練習。

部署後在網站主機執行：

```sh
node scripts/import-contest-practice.mjs --check
node scripts/import-contest-practice.mjs --db /opt/online-judge/oj.db
```

`--check` 不開啟資料庫；匯入時需明確指定既有 SQLite 路徑，會先建立一致性備份。重跑會保留原題、管理員編輯及測資，不會再次新增。題目另標為「競賽練習」，與歷屆正式試題區分。
