# CPE 逐題教學

教學對應本站 CPE 題庫 a460～a847，共 388 題。每題包含個別解題推導、複雜度、常見陷阱、數值步驟動畫，以及可獨立執行的 C++17／Python 3 程式，不以通用主題範本代替該題解法。

## 入口與資料

- `/courses/cpe`：依主題、教學難度、題號、名稱或方法選課；單元內依難度及題號排序。
- `/courses/cpe/lessons/<題號>`：逐題教學與前後課導覽。
- 題目頁的「教學」按鈕會連至對應課程；既有 APCS／TOI 課程連結保持原規則。

這是程式內建的公開學習路徑，不新增資料庫 `Course`／`CourseMember`，不需加入代碼，也不改動既有題號、題目難度、測資或提交。登入後以本人不重複的 AC 題目計算進度。

公開入口會同時核對實際題目的類型、CPE 標籤與公開狀態。已隱藏、刪除、移除 CPE 標籤、未列入教材清單或非實作題的題目，不會因為打包了教材而開放閱讀；管理員仍可預覽未公開實作題。前後課也只包含目前有權閱讀的題目。

`src/lib/cpeProblemCatalog.ts` 保存從本站公開頁取得的題名及公開範例，不含隱藏測資；內容以 2026-10-20 的本站題敘為準，不假設同題號 UVa 版本的規格必然完全一致。新增或修改題目時，應重新核對題意、範例與限制，而不是只調整題名。

教材使用 `defineCpeLesson`，依主題與難度分類並自動帶入公開範例。動畫可採較小的示意資料，但需明確標示，且所有狀態與計算必須一致。增加題目時同步更新題目清單、教材索引與覆蓋檢查；新出現在題庫的 CPE 題目不會自動取得不存在的教學。

## 驗證

結構與完整覆蓋：

```sh
npm run test:cpe-lessons
```

實際執行所有公開範例：

```sh
npm run test:cpe-lessons -- --python python3 --cxx g++
```

可用 `--batch 1` 到 `--batch 6` 分批驗證，或用 `--file batch1/part1`、`--file final` 驗證單個內容檔。`--code a460,a461` 可再限制題號。C++ 執行需同時提供 Python 路徑，作為跨平台的編譯與程序執行器。

比對保留內部空白與空白行，只正規化換行及行尾空白，以檢查文字圖形、標籤與多筆資料的輸出格式。驗證不會向線上評測送出程式；公開範例通過不代表所有隱藏測資均通過，進階題仍需獨立暴力比對及邊界測試。

Windows Clang 驗證會在暫存測試檔展開 GNU 的便利標頭，並可使用共同標準標頭的預編譯檔；教材本身不受更動。可用 `--no-pch` 停用預編譯，`--temp-root <目錄>` 指定可寫的暫存位置。若端點保護阻擋新執行檔，不能將「編譯成功」視為「執行通過」；使用 `--compile-only-cxx` 可只編譯 C++ 並繼續測試 Python，完整執行另由 Linux CI 驗證，不修改安全設定。

HTTP 整合驗證會建立拋棄式資料庫、執行 migration 並啟動本機網站，涵蓋搜尋、分類、入口、隱藏題目、前後課、題目頁按鈕與本人進度，不使用正式資料庫：

```sh
npm run test:cpe-course
```

若已完成 production build，可設 `CPE_TEST_PRODUCTION=1` 重用建置結果。CI 同時執行完整應用程式檢查與七個分片的 C++／Python 公開範例驗證。
